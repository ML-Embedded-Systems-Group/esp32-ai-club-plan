## Phase 2: Coding, RUNTIME.py, the runtime seed (about 1-2 hours)

This is the first pass at the runtime loop the club will finish in week 2. Build it now:

1. Download the real model file: https://github.com/slvDev/esp32-ai/raw/main/src/model.bin . Save it as model.bin in your working folder.
2. Write a script, under 60 lines, stdlib only (struct, time).
3. Load model.bin: treat the first 10 KB as the head, the rest as the table. Row stride: 512 bytes. The real layout gets fixed in week 2; this pass proves the loop.
4. 20 steps. Each step: read 6 rows from the table, find the largest value in the 6 rows, use its index as the next token id, print it.
5. Time each step with time.perf_counter. Print each step time, the average, and the tok/s: 1,000,000 divided by the average in us.
6. Write a comment at the top: what must change in week 2 (the real layout, the real head).

Save it as RUNTIME.py. Run it and keep the output. Write the script yourself. Do not paste from any AI tool.

## Phase 3: Maths, measured speed (about 1 hour)
