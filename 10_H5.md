# H5: Softmax

Member: ____________
Time budget: 8-10 hours

## Goal

Explain how softmax changes logits into probabilities. Measure the cost of a small decode loop.

## Phase 1: Read the Resource (2-3 hours)

Read https://en.wikipedia.org/wiki/Softmax_function.

Focus on exponentials, normalization, temperature, and the largest logit. Write a summary in your own words.

## Phase 2: Solve the Maths (2 hours)

1. Calculate softmax for logits `[1, 2, 3]`.
2. Show the three exponentials, their sum, and each probability.
3. Compare with `0.090`, `0.245`, and `0.665`.
4. Calculate softmax for the same logits at temperature `10`.
5. Explain why the result is closer to uniform.
6. Explain why the largest logit keeps the largest probability.

## Phase 3: Write and Run `SOFTMAX_REPRO.py` (2-3 hours)

Write a script under 70 lines. Use `math`, `random`, and `time` only.

1. Implement temperature softmax.
2. Test probability sums for 100 random vectors.
3. Test argmax preservation for the same vectors.
4. Print softmax for `[1, 2, 3]` at temperatures `1` and `10`.
5. Run the 20-step fake decode loop from the original task.
6. Print average step time and tokens per second.
