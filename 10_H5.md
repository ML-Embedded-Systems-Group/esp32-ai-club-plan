## Part 2: Your deliverable, what the runtime does (about 2-3 hours)

Write WHAT_THE_RUNTIME_DOES.md.

1. Explain what the runtime is: the program on the chip that generates text. Answer in 5-7 sentences.
2. Describe one generation step, in order: read 6 rows of the table from flash, run the core, scan the head in PSRAM, pick the next token, repeat. One sentence per stage.
3. Answer in writing: why does the runtime read only 6 rows of the table per token instead of all 25M values? What tells it which rows to read?
4. The results page says the table is 25M values but only about 450 bytes of table are read per token. Explain the difference in your own words.

Rules: plain words only. No copy-paste. Write everything yourself. Do not paste from any AI tool. The meetup questions will show the difference.
