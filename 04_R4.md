## Phase 2: Coding, PPL_CHECK.py (about 1-2 hours)

Write a Python script with these requirements:

- Under 30 lines. No libraries.
- A dict named PROBS_A: cat 0.5, dog 0.3, sun 0.2.
- A dict named PROBS_B: cat 0.4, dog 0.35, sun 0.25.
- A list named SEQ: cat, sun, dog, cat.
- For each dict: multiply the 4 probabilities of SEQ, print the product. Then compute ppl = product to the power -1/4. Print it, rounded to 2 decimals.
- Print which ppl is lower.

Save it as PPL_CHECK.py. Run it and keep the output. Write the script yourself. Do not paste from any AI tool.
