## Phase 2: Coding, PPL_FROM_LOSS.py, the converter (about 1-2 hours)

The club uses this on every eval run. Build it now:

- Under 25 lines, stdlib only.
- The script takes a loss value as an argument. It computes ppl = e to the power of the loss (math.exp).
- It prints: the loss, the ppl rounded to 2 decimals, and the average per-word probability: 1 divided by ppl.
- If no argument is given, it uses the repo's reported ppl of 12.58 and computes the loss backwards: math.log(12.58).
- Run it both ways: loss to ppl, and ppl 12.58 to loss. Keep both outputs.

Save it as PPL_FROM_LOSS.py. Write the script yourself. Do not paste from any AI tool.
