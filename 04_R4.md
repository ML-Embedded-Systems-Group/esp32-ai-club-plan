# R4: Sigmoid neurons

Member: ____________
Time budget: 8-10 hours

## Goal

Explain a sigmoid neuron and its derivative. Run one forward pass through a small network.

## Phase 1: Read the Resource (2-3 hours)

Read chapter 1 of Michael Nielsen's Neural Networks and Deep Learning:

http://neuralnetworksanddeeplearning.com/chap1.html

Focus on weighted sums, bias, sigmoid output, and sigmoid derivatives. Write a summary in your own words.

## Phase 2: Solve the Maths (2 hours)

Use weights `[0.5, -1.0]`, bias `0.2`, and inputs `[2.0, 1.0]`.

1. Calculate the weighted sum plus bias.
2. Calculate the sigmoid. Expected value: `0.550`.
3. Calculate the sigmoid of the negative sum. Expected value: `0.450`.
4. Calculate the derivative with `sigma * (1 - sigma)`.
5. Calculate it again with a small difference quotient.
6. Show that both derivatives round to `0.248`.

## Phase 3: Write and Run `NN_FWD_REPRO.py` (2-3 hours)

Write a script under 50 lines. Use only the Python standard library.

1. Implement the sigmoid and derivative.
2. Reproduce the phase 2 neuron.
3. Test both identities over 100 values from `-5` to `5`.
4. Print the largest deviation for each identity.
5. Build a 2-2-1 network with your own weights.
6. Print one forward-pass output.

## Phase 4: Write `NN_FWD.md` (2 hours)

Write at least 350 words. Use `## Resource Summary`, `## Maths`, `## Script Output`, `## Why the Identities Matter`, and `## What I Still Need to Learn`.
