## Phase 2: Maths (about 2 hours)

Problem 1: x = [1.0, 2.0, 3.0], p = 0.5. Dropout turns each element into x times a Bernoulli draw: the element stays with probability p, and is multiplied by 1/p. For the first element, compute the expected value by hand. Show both cases with their probabilities.

Verify: the expected value of the first element is exactly 1.0.

Problem 2: repeat the expectation for p = 0.8. Show the steps.

Verify: the expected value is still 1.0.

Problem 3: derive the general rule with symbols: x times the Bernoulli draw, divided by p. Show that the expected value always equals x, for any p.

This is the meeting check. The lead asks you 2 questions from this phase.

## Phase 3: Coding, DROPOUT_REPRO.py (about 2-3 hours)

Write a script, under 40 lines, stdlib only (random):

1. Implement dropout with the scaling rule from the paper.
2. Run x = [1.0, 2.0, 3.0] for 100,000 trials at p = 0.5. Print the mean of each element.
3. Verify: each mean is within 0.05 of the original value. Print pass or fail.
4. Repeat at p = 0.2 and p = 0.8. Verify the same.
5. Run the same trials without the 1/p scaling. Print the means. Verify: each mean is now near p times the original value. Print pass or fail.

Save it as DROPOUT_REPRO.py. Write the script yourself. Do not paste from any AI tool.
