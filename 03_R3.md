## Phase 2: Coding, BPE_ENCODE.py, the encoder core (about 1-2 hours)

The chip runs this same algorithm. Build a working encoder now:

1. Download the real GPT-2 tokenizer files:
   - https://huggingface.co/gpt2/resolve/main/merges.txt
   - https://huggingface.co/gpt2/resolve/main/vocab.json
   Save them in your working folder.
2. Write a script, under 60 lines, stdlib only. It loads merges.txt (the merge rules, one per line) and vocab.json (piece to id).
3. Implement encode(text): split the text into characters and spaces. Then apply the merge rules in order: for each rule, scan the token list and merge every adjacent pair that matches the rule. This is a real BPE encoder, slow but correct.
4. The script takes the text as an argument. It prints: the final pieces, their ids, and the token count.
5. Run it on 5 sentences of your choice. Print the token counts.

Save it as BPE_ENCODE.py. Write the script yourself. Do not paste from any AI tool.

## Phase 3: Maths, vocab bits (about 1 hour)

Show every step:

1. GPT-2 vocab is 50257. Compute the bits per index: 2 to the power 15 is 32768, 2 to the power 16 is 65536. Which power covers 50257?
2. LLaMA vocab is 32000. Which power covers it?
3. The repo vocab is 32768. Which power is it exactly?
4. One million tokens at 15 bits: compute the size in bits, then in MB (divide by 8, then by 1,000,000). Compare with one million tokens at 16 bits.
