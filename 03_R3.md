## Phase 2: Coding, BPE_MERGE.py (about 1-2 hours)

Write a Python script with these requirements:

- Under 50 lines. No libraries.
- A short text of 5 to 8 words, hardcoded as a string.
- Round 1: split the text into characters and spaces. Count every adjacent pair. Print the pair counts, sorted.
- Merge the most frequent pair: replace it in the text. Print the new text.
- Round 2: repeat the count and the merge. Print both rounds.
- You must write the counting loop yourself. No Counter, no itertools.

Save it as BPE_MERGE.py. Run it and keep the output. Write the script yourself. Do not paste from any AI tool.

## Phase 3: Maths, vocab bits (about 1 hour)

Show every step:

1. GPT-2 vocab is 50257. Compute the bits per index: 2 to the power 15 is 32768, 2 to the power 16 is 65536. Which power covers 50257?
2. LLaMA vocab is 32000. Which power covers it?
3. The repo vocab is 32768. Which power is it exactly?
4. One million tokens at 15 bits: compute the size in bits, then in MB (divide by 8, then by 1,000,000). Compare with one million tokens at 16 bits.
