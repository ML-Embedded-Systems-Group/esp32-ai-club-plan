2. Implement logistic regression with gradient descent: learning rate 0.1, 1000 steps. Print the loss every 100 steps.

4. Verify: the model classifies all 6 points correctly. Print pass or fail.
5. Verify: the sigmoid of z plus the sigmoid of minus z equals 1, for 100 random values of z. Print the biggest deviation.
