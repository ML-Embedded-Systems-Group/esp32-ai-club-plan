## Phase 2: Coding, PWM dimmer in Wokwi (about 2-3 hours)

Write a firmware program with PWM. No template code.

1. Open https://wokwi.com. Start a new ESP32 project.
2. Delete the template program completely.
3. Write the whole program yourself, under 50 lines: configure one PWM channel (ledcSetup and ledcAttachPin), then fade the LED: a loop that raises the duty from 0 to 255 and back, with a small delay per step.
4. Run it. The LED must visibly brighten and dim.
5. Take two screenshots at different brightness levels. Save them as PWM_LOW.png and PWM_HIGH.png.
6. Your program must compile and run in the simulator.

Write the program yourself. Do not paste from any AI tool or from the template.

## Phase 3: Maths, PWM (about 1-2 hours)

Show every step, with units:

1. PWM frequency 5000 Hz: period = 1 divided by 5000, in microseconds.
2. Duty 50%: on time = 50% of the period. Compute in microseconds. Duty 25%: same.
3. 8-bit resolution: 256 duty levels. One step as a percentage: 1 divided by 256, times 100.
4. On time for duty values 64, 128, and 192 at 5000 Hz.
5. Write 2 sentences: why PWM instead of delay, and what the resolution limits.
