## Phase 2: Coding, RESULTS_CHECK.py, the results checker (about 1-2 hours)

This script will check the club's own results every week. Build it now:

1. Download the raw results file: https://raw.githubusercontent.com/slvDev/esp32-ai/main/RESULTS.md . Save it as RESULTS.md in your working folder.
2. Write a script, under 40 lines, stdlib only. It reads RESULTS.md line by line.
3. For each table row (lines that start with |), split the cells, collect the numeric cells.
4. Print every row: the label and the numbers. Print how many rows were parsed.
5. For the tok/s column: derive ms per token (1000 divided by tok/s) and print it next to the row.
6. If a row has no numbers, print a warning with the row label.
7. The script must work on any results file with the same shape, so the club can run it next week on its own numbers.

Save it as RESULTS_CHECK.py. Write the script yourself. Do not paste from any AI tool.

## Phase 3: Maths, compression (about 1 hour)

The repo model is 14.9 MB at 4 bits per value. Show every step:

1. Bytes per value at 4 bits: 4 bits = 0.5 byte. Compute the number of values: 14.9 MB in bytes, divided by 0.5.
2. Size at 16 bits (fp16): number of values times 2 bytes.
3. Compression ratio: fp16 size divided by 4-bit size. Round to 1 decimal.
4. Write the ratio in one sentence.
