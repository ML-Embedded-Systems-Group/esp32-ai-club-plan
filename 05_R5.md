## Phase 2: Coding, ERROR_STUDY.py, the design tool (about 1-2 hours)

The club uses this to pick the group size for real weights. Build it now:

1. Write a script, under 50 lines, stdlib only (math, random, struct).
2. Generate 1000 random values between -1 and 1. Write them to RAW.bin as fp16 with struct.pack (2 bytes per value).
3. For group sizes 1, 4, and 16: read RAW.bin, quantize every group to 4-bit levels with one scale per group, dequantize.
4. Print one table row per group size: the group size, the bytes used, the total error (sum of absolute errors).
5. The table is the club's design data: which group size fits which error budget.

Save it as ERROR_STUDY.py. Run it and keep the output. Write the script yourself. Do not paste from any AI tool.

## Phase 3: Maths, bits accounting (about 1 hour)

Show every step, for the 1000 values:

1. fp16: 1000 values times 16 bits. Total in bits.
2. Groups of 4: 1000 times 4 bits for the values, plus 250 scales times 8 bits. Total in bits.
3. Groups of 16: 1000 times 4 bits, plus 63 scales times 8 bits. Total in bits.
4. Compression ratio vs fp16 for both: total bits divided by fp16 bits. Round to 2 decimals.
5. Two sentences: why bigger groups use fewer bits, and what that costs.
