## Phase 2: Coding, QUANTIZE_TOY.py (about 1-2 hours)

Write a Python script with these requirements:

- Under 40 lines. No libraries beyond math and random.
- Generate 20 random values between -1 and 1. Split them into groups of 4.
- For each group: scale = the largest absolute value. Quantize each value to 4 bits: round to the nearest of 16 levels between -scale and scale. Dequantize: level times scale divided by 8.
- Print per group: original values, reconstructed values, error per value.
- Repeat the whole thing with groups of 1 (scale per value). Print the total error for both runs: sum of absolute errors.
- Print which run has the smaller total error.

Save it as QUANTIZE_TOY.py. Run it and keep both outputs. Write the script yourself. Do not paste from any AI tool.

## Phase 3: Maths, bits accounting (about 1 hour)

Show every step, for the 20 values:

1. fp16: 20 values times 16 bits. Total in bits.
2. Groups of 4: 20 times 4 bits for the values, plus 5 scales times 8 bits. Total in bits.
3. Groups of 1: 20 times 4 bits, plus 20 scales times 8 bits. Total in bits.
4. Compression ratio vs fp16 for both runs: total bits divided by fp16 bits. Round to 2 decimals.
5. Two sentences: why groups of 4 use fewer bits, and what that costs.
