## Phase 2: Maths, quantization by hand (about 2 hours)

Show every step:

1. Affine quantization, b bits: scale = (max - min) divided by (2 to the power b minus 1). Compute the scale for 8 bits on x = [1.0, 2.0, 3.0, 4.0].
2. Zero point: the integer that maps the minimum to the minimum quantized range: z = round(-min divided by scale) for a symmetric setup, or the article's formula. Use the article's formula.
3. Quantize: q = round(x divided by scale plus zero point). Compute q for all 4 values.
4. Dequantize: xhat = (q minus zero point) times scale. Compute all 4.
5. Error: x minus xhat for every value. The bound is scale divided by 2. Verify every error is within the bound.
6. Repeat the scale and one value for 4 bits. Write 2 sentences: what 8 to 4 bits changes, and where the error comes from.
