# R5: Backpropagation

Member: ____________
Time budget: 8-10 hours

## Goal

Explain how backpropagation calculates gradients and updates weights. Train a small network on AND.

## Phase 1: Read the Resource (2-3 hours)

Read https://www.geeksforgeeks.org/backpropagation-in-neural-network/.

Focus on the forward pass, error, gradients, chain rule, and weight updates. Write a summary in your own words.

## Phase 2: Solve the Maths (2 hours)

Use input `(1, 1)`, target `1`, weights `w1 = w2 = 0.2`, bias `b = 0`, learning rate `0.5`, and mean squared error.

1. Calculate the forward pass.
2. Calculate the error and loss.
3. Calculate the gradient for each weight and the bias.
4. Update all three values.
5. Show every step.
6. Compare `w1 = w2 = 0.248` and the lower loss.

## Phase 3: Write and Run `NN_TRAIN_REPRO.py` (2-3 hours)

Build a 2-2-1 sigmoid network under 70 lines.

1. Train on all four AND inputs for 5,000 updates.
2. Print the loss every 500 updates.
3. Print `PASS` when the final loss is lower.
4. Print `PASS` when all outputs are within `0.1` of their targets.
5. Print the final prediction for every input.

## Phase 4: Write `NN_TRAIN.md` (2 hours)

Write at least 350 words. Use `## Resource Summary`, `## Maths`, `## Script Output`, `## How the Network Learned AND`, and `## What I Still Need to Learn`.
