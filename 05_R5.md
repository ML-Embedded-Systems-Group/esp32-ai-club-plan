## Part 2: Your artifact, quantize real numbers (about 2-3 hours)

1. Write a tiny Python script, under 40 lines. No libraries beyond math and random.
2. Generate 20 random values between -1 and 1. Split them into groups of 4.
3. For each group: scale = the largest absolute value. Quantize each value to 4 bits: round to the nearest of 16 levels between -scale and scale. Dequantize. Print original, reconstructed, and error per group.
4. Run it again with groups of 1 (scale per value). Print the total error for both runs. Which is smaller? Why?
5. Save as QUANTIZE_TOY.py. Paste the outputs into QUANTIZE_TOY.md. Push both to this repo.

Rules: write the script yourself. No copy-paste. Do not paste from any AI tool. The meetup questions will show the difference.
