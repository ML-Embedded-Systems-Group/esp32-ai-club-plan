## Phase 1: Reading (about 2-3 hours)

https://arxiv.org/abs/1712.05877

You need the quantization scheme in section 2: the affine mapping between a real value r and an integer q, with the scale S and the zero point Z.

## Phase 2: Maths (about 2 hours)

Problem 1: quantize x = [1.0, 2.0, 3.0, 4.0] to 8 bits with the paper's affine scheme. Find the scale S from the range of x, find the zero point Z, quantize the four values, then dequantize them. Show every step.

Verify: every dequantization error is at most S/2.

Problem 2: repeat for 4 bits on the same vector.

Verify: the bound still holds, and the 4-bit scale is 16 times the 8-bit scale.

This is the meeting check. The lead asks you 2 questions from this phase.

## Phase 3: Coding, QUANT_REPRO.py (about 2-3 hours)

Write a script, under 60 lines, stdlib only:

1. Implement the paper's affine quantization: quantize and dequantize, with S and Z from the paper's formulas.
2. Run it on x = [1.0, 2.0, 3.0, 4.0] at 8 bits. Print S, Z, the quantized values, the dequantized values, and the errors.
3. Verify: every error is at most S/2. Print pass or fail.
4. Run the same vector at 4 bits. Print the error table and the ratio: 4-bit error divided by 8-bit error.
5. Verify: the 4-bit scale is 16 times the 8-bit scale. Print pass or fail.
6. The script must accept any vector, so the club can reuse it in week 2.

Save it as QUANT_REPRO.py. Write the script yourself. Do not paste from any AI tool.
