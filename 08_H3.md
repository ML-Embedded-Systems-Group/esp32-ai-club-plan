## Part 2: Your artifact, pack values into 4 bits (about 2-3 hours)

1. Write a Python script, under 50 lines. No libraries beyond math and random.
2. Generate 1000 random values. Split them into groups of 16.
3. For each group: scale = the largest absolute value. Quantize to 4 bits: round to the nearest of 16 levels. Pack 2 values into 1 byte.
4. Unpack and dequantize. Print the round-trip error and the total bytes used. Compare with 1000 values at 16 bits.
5. Save as PACK_TOY.py. Paste the output into PACK_TOY.md. Push both to this repo.

Rules: write the script yourself. No copy-paste. Do not paste from any AI tool. The meetup questions will show the difference.
