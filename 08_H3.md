## Phase 2: Coding, PACK_BIN.py, the packer (about 2-3 hours)

This is the packing step the club runs on real weights. Build it now:

1. Get a raw values file: use RAW.bin from R5 (ask your pair) or generate it: 1000 fp16 values between -1 and 1, struct.pack, 2 bytes per value.
2. Write a script, under 70 lines, stdlib only (struct, math).
3. Read RAW.bin. Split the values into groups of 16. For each group: scale = the largest absolute value. Quantize to 4-bit levels: round to the nearest of 16 levels.
4. Pack: 2 levels per byte, level times 16 plus level. Keep one scale byte per group.
5. Write the packed bytes and the scales to PACKED.bin.
6. Read PACKED.bin back, unpack, dequantize. Verify against the original values. Print: the sum of absolute errors and the maximum absolute error.
7. Print: bytes in RAW.bin, bytes in PACKED.bin, and the compression ratio.
8. The script must accept any raw values file, so the club can pack real weights in week 2.
9. Also print the first 3 groups in detail: original values, levels, reconstructed values.

Save it as PACK_BIN.py. Run it. Write the script yourself. Do not paste from any AI tool.

## Phase 3: Maths, byte accounting (about 2 hours)

Show every step, for the 1000 values:

1. Values at 4 bits: 1000 times 4 bits. Convert to bytes: divide by 8.
2. Scales: 1000 divided by 16 is 63 groups (62 full, 1 partial). 63 scale bytes.
3. Total packed bytes: values bytes plus scale bytes.
4. fp16: 1000 values times 2 bytes.
5. Compression ratio: fp16 bytes divided by packed bytes. Round to 2 decimals.
6. If the group were 32: scale count, scale bytes, total bytes, ratio. Compare with group 16.
7. The real model: 14.9 MB packed at 4 bits. What would it be in fp16? Write the comparison.
8. Write 2 sentences: what the scale bytes cost, and why the format needs a header in week 2.
