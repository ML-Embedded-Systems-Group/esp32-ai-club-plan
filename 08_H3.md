# H3: Little-endian and big-endian data

Member: ____________
Time budget: 8-10 hours

## Goal

Explain byte order. Convert integer values to memory bytes for both byte orders.

## Phase 1: Read the Resource (2-3 hours)

Read https://www.geeksforgeeks.org/little-and-big-endian-mystery/.

Focus on byte order, multi-byte integers, and the effect of byte order on files. Write a summary in your own words.

## Phase 2: Solve the Maths (2 hours)

1. Write `0x12345678` in big-endian memory order.
2. Write the same value in little-endian memory order.
3. Convert `0xABCD` for the little-endian ESP32-S3.
4. Show every byte.
5. Compare with `12 34 56 78`, `78 56 34 12`, and `CD AB`.

## Phase 3: Write and Run `ENDIAN_REPRO.py` (2-3 hours)

Write a script under 60 lines.

1. Convert integers with shifts, not `struct`.
2. Print both byte orders for `0x12345678` and `0xABCD`.
3. Print `PASS` for all expected byte lists.
4. Print the host byte order with `sys.byteorder`.
5. Test a `struct.pack` and `struct.unpack` round trip.

## Phase 4: Write `ENDIAN.md` (2 hours)

Write at least 350 words. Use `## Resource Summary`, `## Maths`, `## Script Output`, `## Why Byte Order Matters`, and `## What I Still Need to Learn`.
