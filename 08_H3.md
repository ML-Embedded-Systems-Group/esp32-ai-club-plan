## Phase 2: Coding, PACK_TOY.py (about 1-2 hours)

Write a Python script with these requirements:

- Under 50 lines. No libraries beyond math and random.
- Generate 1000 random values between -1 and 1. Split them into groups of 16.
- For each group: scale = the largest absolute value. Quantize each value to 4 bits: round to the nearest of 16 levels.
- Pack: 2 values per byte. Level times 16 plus level, as an integer. Store the bytes in a bytearray. Keep one scale byte per group.
- Unpack: read the bytes back, split the levels, dequantize with the scales.
- Print: bytes used by the packed file, bytes for 1000 values at 16 bits, and the round-trip error (sum of absolute errors).

Save it as PACK_TOY.py. Run it and keep the output. Write the script yourself. Do not paste from any AI tool.

## Phase 3: Maths, byte accounting (about 1 hour)

Show every step, for the 1000 values:

1. 1000 values times 4 bits. Convert to bytes: divide by 8.
2. Scales: 1000 divided by 16 = 63 groups. 63 scale bytes.
3. Total packed bytes: values bytes plus scale bytes.
4. fp16: 1000 values times 2 bytes.
5. Compression ratio: fp16 bytes divided by packed bytes. Round to 2 decimals.
6. Two sentences: what the scale bytes cost, and how a bigger group changes that.
