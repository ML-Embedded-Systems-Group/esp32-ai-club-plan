# Submissions

Keep each member's work together:

```text
submissions/week-1/<task>_<member>/
submissions/week-2/<paper>_<member>/
```

Week 1 folders contain the report and any required reproduction program. Week 2 folders contain only the 400–600 word Markdown research-paper summary; Week 2 has no code.

Task guides are [`tasks/week-1/`](../tasks/week-1/) and [`tasks/week-2/`](../tasks/week-2/). Pull requests should add files to the matching submissions folder and be reviewed before merge.
