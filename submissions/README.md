# Submissions

Keep each member's work together:

```text
submissions/week-1/<task>_<member>/
submissions/week-2/<paper>_<member>/
submissions/week-3/<member>/
```

Week 1 folders contain the report and any required reproduction program. Week 2 folders contain only the 400 to 600 word Markdown research-paper summary; Week 2 has no code. Week 3 folders contain `student_forward.py`, `RUNS.md`, and `PROPOSAL.md`.

Task guides are [`tasks/week-1/`](../tasks/week-1/), [`tasks/week-2/`](../tasks/week-2/), and [`tasks/week-3/`](../tasks/week-3/). Pull requests should add files to the matching submissions folder and be reviewed before merge.
