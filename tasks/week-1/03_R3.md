# R3: Logistic regression

Member: ____________
Time budget: 8-10 hours

## Goal

Explain the sigmoid, binary cross-entropy, and the decision boundary. Classify two groups of points.

## Phase 1: Read the Resource (2-3 hours)

Read https://mlu-explain.github.io/logistic-regression/.

Focus on the sigmoid, probability output, decision boundary, and loss. Write a summary in your own words.

## Phase 2: Solve the Maths (2 hours)

Use `w = [1.0, -0.5]`, `b = 0.1`, and `x = [2.0, 3.0]`.

1. Calculate the logit `z`.
2. Calculate the sigmoid. Expected value: `0.646`.
3. Calculate binary cross-entropy for label `1`. Expected value: `0.437`.
4. Show that `sigmoid(z) + sigmoid(-z) = 1`.

## Phase 3: Write and Run `LOGREG_REPRO.py` (2-3 hours)

Use these six points. Write a script under 70 lines.

Class 0:
- [1.0, 1.0]
- [1.5, 2.0]
- [2.0, 1.5]

Class 1:
- [4.0, 4.0]
- [4.5, 5.0]
- [5.0, 4.5]

1. Implement logistic regression with learning rate `0.1` and 1,000 updates.
2. Print the loss every 100 updates.
3. Print `PASS` when the final loss is below the initial loss.
4. Print `PASS` when all six points are classified correctly.
5. Test the sigmoid identity with 100 random values.
6. Print the decision boundary where `z = 0`.
