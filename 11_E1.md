## Phase 1: Reading (about 2-3 hours)

Read these in order:

1. What an ESP32 is: https://docs.espressif.com/projects/esp-idf/en/latest/esp32s3/ (read the introduction)
2. The board overview: https://docs.espressif.com/projects/esp-idf/en/latest/esp32s3/api-guides/ (read the names of the sections, then the one on memory)
3. The project readme: https://github.com/slvDev/esp32-ai (read the description, skip the code)

For each source, write in your log:
- what it is, in one line
- 3 things you learned
- 1 question you still have

Write in your own words. Do not copy-paste.

## Phase 2: Coding, in the Wokwi simulator (about 1-2 hours)

Work in the browser, no installs:

1. Open https://wokwi.com. Start a new ESP32 project, the blinking LED example.
2. Press Play. Watch the LED blink. Take a screenshot and save it as WOKWI_RUN.png.
3. Find the ESP32 chip and the LED in the simulator. Note the chip name and the LED pin.
4. In the code editor, find the delay call. Write down the number you see.

Write nothing into the code yet. The edit is E2's task.

## Phase 3: Doc generation, WOKWI_RUN.md (about 1 hour)

Build WOKWI_RUN.md with these parts:

- WOKWI_RUN.png, embedded.
- The chip name and the LED pin you found.
- 3 sentences in your own words: which board parts you see, where the program lives in the sim, and what the sim does for you.

Push WOKWI_RUN.md and WOKWI_RUN.png to this repo.
