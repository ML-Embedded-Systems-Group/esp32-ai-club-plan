# E1: Repository setup and build

Member: ____________
Time budget: 7-9 hours

## Goal

Run the project on the host. Record the repository structure, test result, and model fetch result.

## Phase 1: Read the Repository (2-3 hours)

Read https://github.com/slvDev/esp32-ai in this order:

1. The repository README.
2. `RESULTS.md`.
3. `firmware/esp32_barista/README.md`.
4. `firmware/esp32_tinystories/README.md`.

Record the project purpose, the 28.9M parameter model, and the published `9.88 tokens per second` result. Write the summary in your own words.

## Phase 2: Install and Build (2-3 hours)

Run these tasks on the host:

1. Install Python 3 and `uv` from `pyproject.toml` and `.python-version`.
2. Install the project with `uv` and the lock file.
3. Run `pytest` and record the test count and result.
4. Run `scripts/fetch_model.sh` with the barista model.
5. Run `scripts/benchmark_device.py` when it supports host execution.

Do not install ESP-IDF this week. Do not use a board. Record exact commands, versions, and errors.

## Phase 3: Map the Repository (2-3 hours)

Answer these questions from the code:

1. What does each top-level folder contain?
2. What do `src/model.py` and `src/quantize.py` do?
3. What do `fetch_model.sh` and `deploy.sh` do?
4. Which tasks run on the host?
5. Which tasks need the board?

## Phase 4: Write `REPO_MAP.md` (1-2 hours)

Write at least 300 words. Use `## Project Summary`, `## Folder Map`, `## Toolchain`, `## Build Results`, and `## Host and Board Work`.

Include the build log, test result, model fetch result, and command versions. Do not include any downloaded model.
