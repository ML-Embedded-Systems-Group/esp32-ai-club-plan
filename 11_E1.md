## Phase 2: Coding, blink from scratch in Wokwi (about 2-3 hours)

Write a full firmware program yourself. No template code.

1. Open https://wokwi.com. Start a new ESP32 project.
2. Delete the template program completely.
3. Write the whole program yourself, under 30 lines: one GPIO pin as output, an infinite loop that sets the pin high, waits, sets it low, waits.
4. Use the delay function with a 1000 ms value, then run it with 200 ms. The LED must blink in both cases.
5. Take a screenshot of the running simulator for each delay. Save them as BLINK_1000.png and BLINK_200.png.
6. Your program must compile and run in the simulator.

Write the program yourself. Do not paste from any AI tool or from the template.

## Phase 3: Maths, clock and delay (about 1-2 hours)

The ESP32-S3 runs at 240 MHz. Show every step, with units:

1. Cycles per second at 240 MHz: 240,000,000. Cycle time: 1 divided by 240,000,000, in nanoseconds.
2. A delay of 1000 ms: how many CPU cycles is that? 240,000,000 times 1 second.
3. If one loop iteration takes about 10 cycles, how many iterations does the 1000 ms delay need? 240,000,000 divided by 10.
4. The LED blinks on for 1000 ms and off for 1000 ms. Full period: 2 seconds. Frequency: 1 divided by 2, in Hz.
5. Same for the 200 ms delay: period and frequency.
6. Write 2 sentences: what the delay function costs, and why a busy wait is a bad idea for real firmware.
