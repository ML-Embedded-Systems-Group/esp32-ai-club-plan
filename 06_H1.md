## Phase 2: Coding, FLOW_BENCH.py, the read benchmark (about 1-2 hours)

The club needs to know how flash reads compare on this machine vs the chip. Build it now:

1. Download the real model file: https://github.com/slvDev/esp32-ai/raw/main/src/model.bin . Save it as model.bin in your working folder.
2. Write a script, under 40 lines, stdlib only (time, os).
3. Read model.bin in 512-byte chunks. Time every read with time.perf_counter.
4. Print: the file size, the number of chunks, the average microseconds per read.
5. One token on the chip needs 6 row reads. Print the projected tok/s on this machine: 1,000,000 divided by (6 times the average read time in us).
6. Run it 3 times. Keep the 3 outputs.

Save it as FLOW_BENCH.py. Write the script yourself. Do not paste from any AI tool.

## Phase 3: Maths, memory budget (about 1 hour)

Show every step:

1. Flash: 16 MB total. The model.bin is 14.9 MB. Compute the free flash: 16 minus 14.9.
2. Compute the free flash as a percentage of 16 MB.
3. SRAM is 512 KB. Divide 14.9 MB by 0.5 MB. How many times bigger is the model than SRAM?
4. Two sentences: where the table lives and why it cannot live in SRAM.
