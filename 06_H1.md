## Part 2: Your artifact, the model to device diagram (about 2-3 hours)

1. Open https://excalidraw.com. No account needed.
2. Draw the full flow as boxes: training, quantization, export to model.bin, flash, PSRAM, SRAM, runtime, output text. Connect them with arrows.
3. Under each box, write one line. Add the numbers from RESULTS.md where they exist: file size, tok/s, memory free.
4. Export as PNG and save it as MODEL_TO_DEVICE.png.
5. Write a tiny Python script, under 40 lines. It simulates the journey of one token: read rows from flash, run the head in PSRAM, print the token. Use time.perf_counter to print how long the step took. No ML, just print statements.
6. Save it as FLOW_SIM.py and run it.
7. Push MODEL_TO_DEVICE.png and FLOW_SIM.py to this repo.

Rules: the flow must make sense to someone who never saw the repo. Write the script yourself. Do not paste from any AI tool. The meetup questions will show the difference.
