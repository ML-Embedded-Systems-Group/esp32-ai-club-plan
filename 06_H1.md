# H1: IEEE 754 floating point

Member: Sourasish Mitra
Time budget: 8-10 hours across the week.

## Goal

Explain the sign, exponent, and mantissa fields in a 32-bit float. Reproduce two bit patterns.

## Phase 1: Read the Resource (2-3 hours)

Read https://fabiensanglard.net/floating_point_visually_explained/.

Focus on binary fractions, normalization, the exponent bias, and the 32-bit layout. Write a summary in your own words.

## Phase 2: Solve the Maths (2 hours)

1. Convert `3.5` to binary and normalize it.
2. Calculate its sign, biased exponent, and mantissa.
3. Combine the fields. Expected bits: `0x40600000`.
4. Repeat the process for `0.25`. Expected bits: `0x3E800000`.
5. State the single-precision bias and explain its purpose.

## Phase 3: Write and Run `FLOAT_REPRO.py` (2-3 hours)

Write a script under 50 lines. Do not use `struct` for the conversion.

1. Convert `3.5` and `0.25` into fields and hexadecimal bits.
2. Print `PASS` for both expected values.
3. Convert the bits back into floats.
4. Print `PASS` for both exact round trips.
5. Compare `0.1` in single and double precision.

## Phase 4: Write `FLOAT.md` (2 hours)

Write at least 350 words. Use `## Resource Summary`, `## Maths`, `## Script Output`, `## Why 0.1 Is Not Exact`, and `## What I Still Need to Learn`.
