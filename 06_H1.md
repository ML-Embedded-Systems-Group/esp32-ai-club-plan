## Phase 2: Coding, FLOW_SIM.py (about 1-2 hours)

Write a Python script with these requirements:

- Under 40 lines. No libraries beyond time and random.
- Fake data: a table of 100 rows, 8 values each, random. A fake head of 10 values, random.
- 10 steps. Each step: read 6 rows from the table, print which rows, scan the head, pick the highest value, print the picked index as the token.
- Time each step with time.perf_counter. Print each step time and the average.

Save it as FLOW_SIM.py. Run it and keep the output. Write the script yourself. Do not paste from any AI tool.

## Phase 3: Maths, memory budget (about 1 hour)

Show every step:

1. Flash: 16 MB total. The model.bin is 14.9 MB. Compute the free flash: 16 minus 14.9.
2. Compute the free flash as a percentage of 16 MB.
3. SRAM is 512 KB. Divide 14.9 MB by 0.5 MB. How many times bigger is the model than SRAM?
4. Two sentences: where the table lives and why it cannot live in SRAM.

## Phase 4: Doc generation, MODEL_TO_DEVICE.md (about 1 hour)

- The output of FLOW_SIM.py.
- The maths from phase 3, every step.
