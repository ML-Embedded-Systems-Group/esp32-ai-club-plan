## Phase 2: Maths (about 2 hours)

Verify: the 32 bits are 0x40600000.

Problem 2: write 0.25 in the same layout. Show every step.

## Phase 3: Coding, FLOAT_REPRO.py (about 2-3 hours)

1. Implement your own float to bits converter: sign, exponent with bias, mantissa. Do not use the struct module for the conversion itself.

3. Verify: 0x40600000 and 0x3E800000. Print pass or fail for both.
4. Round trip: turn the bits back into a float. Verify: you recover the original values exactly. Print pass or fail.
5. Print 0.1 as a single precision value and as a double. Print the difference. Note what the article says about this.

Save it as FLOAT_REPRO.py. Write the script yourself. Do not paste from any AI tool.
