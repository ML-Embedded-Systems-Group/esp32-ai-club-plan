## Part 2: Your deliverable, from model to device (about 2-3 hours)

Write MODEL_TO_DEVICE.md.

1. Draw the flow, on paper or in the file: training, quantization, export to model.bin, model file stored in flash, runtime reads weights, chip generates text.
2. Under each stage, write what happens in one line.
3. Where a number exists in RESULTS.md, write it under the stage. Examples: file size, tok/s, memory free numbers.
4. Take a photo of the paper drawing if you drew it by hand, and add it to the file.

Rules: the flow must make sense to someone who never saw the repo. No copy-paste. Write everything yourself. Do not paste from any AI tool. The meetup questions will show the difference.
