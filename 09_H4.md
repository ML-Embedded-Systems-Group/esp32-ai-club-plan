## Phase 3: Coding, BANDWIDTH_REPRO.py (about 2-3 hours)

Write a script, under 40 lines, stdlib only:

1. Implement bandwidth = (bus bits divided by 8) times transfers per second. DDR mode multiplies by 2.
2. Compute the table: DDR3-1600, DDR3-1866, DDR4-2400, DDR4-3200. All 64-bit. Print bus bytes, rate, and bandwidth in GB per second.
3. Verify: 12.8 for DDR3-1600, 25.6 for DDR4-3200. Print pass or fail for both.
4. Club case: the PSRAM estimate from phase 2. Print the required bandwidth for 9.88 tokens per second, 0.5 bytes per value, 14.9 million values: bytes per token times 9.88.
5. Print whether the PSRAM bus can sustain it.

Save it as BANDWIDTH_REPRO.py. Write the script yourself. Do not paste from any AI tool.
