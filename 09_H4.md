## Phase 2: Maths, bandwidth by hand (about 2 hours)

Show every step:

1. DDR3-1600, 64-bit bus. Bus width in bytes: 64 divided by 8. Transfer rate: 1600 million per second. Bandwidth: width times rate. In GB per second.
2. Verify: this is the published 12.8 GB per second for DDR3-1600.
3. DDR4-3200, 64-bit bus. Same steps. The published value is 25.6 GB per second. Verify it.
4. Why the factor 2 for DDR: data transfers twice per clock. Write the full formula: width times clock times 2.
5. The club chip reads PSRAM. If the bus is 8 bits wide and the clock 80 MHz: bandwidth = 1 byte times 80,000,000 times 2. In MB per second.
6. Write 2 sentences: what limits bandwidth, and why the chip is so much slower than a laptop.

## Phase 3: Coding, BANDWIDTH_REPRO.py (about 2-3 hours)

Reproduce the published numbers:

1. Write a script, under 40 lines, stdlib only.
2. Implement bandwidth = (bus bits divided by 8) times transfers per second. DDR mode multiplies by 2.
3. Compute the table: DDR3-1600, DDR3-1866, DDR4-2400, DDR4-3200. All 64-bit. Print bus bytes, rate, bandwidth in GB per second.
4. Verify the published values: 12.8 for DDR3-1600, 25.6 for DDR4-3200. Print match or differ for each.
5. Club case: the PSRAM estimate from phase 2. Print the required bandwidth for 9.88 tokens per second, 0.5 bytes per value, 14.9 million values: bytes per token times 9.88.
