# H2: Memory latency

Member: ____________
Time budget: 8-10 hours

## Goal

Compare cache, memory, and storage latency. Map the values to flash, PSRAM, and SRAM.

## Phase 1: Read the Resource (2-3 hours)

Read the updated interactive latency page:

https://colin-scott.github.io/personal_website/research/interactive_latency.html

Read the entries for L1 cache, L2 cache, RAM, SSD, and disk. Record each value and its unit. Explain why the memory tier affects program speed.

## Phase 2: Solve the Maths (2 hours)

Use L1 `0.5 ns`, L2 `7 ns`, RAM `100 ns`, SSD `150 us`, and disk `10 ms`.

1. Convert SSD and disk to nanoseconds.
2. Calculate RAM over L1.
3. Calculate disk over RAM.
4. Calculate SSD over RAM.
5. Calculate L2 over L1.
6. Compare with `200`, `100000`, `1500`, and `14`.
7. Write two sentences about the largest ratio.

## Phase 3: Write and Run `LATENCY_REPRO.py` (2-3 hours)

Write a script under 50 lines.

1. Store all values in nanoseconds in `TIERS`.
2. Print each tier and its class: cache, memory, or storage.
3. Print every pairwise ratio.
4. Print `PASS` for the RAM and disk checks.
5. Map flash, PSRAM, and SRAM to the closest listed tiers.

## Phase 4: Write `LATENCY.md` (2 hours)

Write at least 350 words. Use `## Resource Summary`, `## Maths`, `## Script Output`, `## ESP32 Memory Mapping`, and `## What I Still Need to Learn`.
