## Phase 2: Maths (about 2 hours)

The list states: L1 0.5 ns, L2 7 ns, RAM 100 ns, SSD 150 us, disk 10 ms.

Problem: compute the four ratios: RAM over L1, disk over RAM, SSD over RAM, L2 over L1. Show every step, including the unit conversions for SSD and disk.

Verify: the ratios must round to 200, 100000, 1500, and 14.

Write 2 sentences: which ratio is the largest, and what it means for a program that reads the wrong tier.

This is the meeting check. The lead asks you 2 questions from this phase.

## Phase 3: Coding, LATENCY_REPRO.py (about 2-3 hours)

Write a script, under 50 lines, stdlib only:

1. A dict named TIERS with the latencies from the list, all in nanoseconds.
2. Print every tier with its latency and a label: cache, memory, or storage.
3. Compute every pairwise ratio. Print the table.
4. Verify: RAM over L1 rounds to 200, disk over RAM rounds to 100000. Print pass or fail for both.
5. Map to the club board: flash, PSRAM, SRAM. Print which of the list's tiers each one behaves like, in one line each.

Save it as LATENCY_REPRO.py. Write the script yourself. Do not paste from any AI tool.
