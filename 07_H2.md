## Phase 2: Coding, MEMORY_BUDGET.py, the placement tool (about 2 hours)

The club checks every candidate model against the board with this script. Build it now:

1. Download the real model file: https://github.com/slvDev/esp32-ai/raw/main/src/model.bin . Save it as model.bin in your working folder.
2. Write a script, under 40 lines, stdlib only (os, math).
3. A dict named BOARD with the tiers: flash 16 MB, PSRAM 8 MB, SRAM 512 KB.
4. Get the model size with os.path.getsize. Print it in MB.
5. For every tier: compute the free space, the model as a percentage of the tier, and print a verdict line: fits or does not fit.
6. The script must work for any model file. The club runs it on every candidate model.
7. Run it on model.bin and keep the output.

Save it as MEMORY_BUDGET.py. Write the script yourself. Do not paste from any AI tool.

## Phase 3: Maths, tier ratios (about 2 hours)

Show every step, with units:

1. SRAM 512 KB: how many times does it fit into flash 16 MB? Divide in KB: 16,000 by 512. Then in MB: 16 by 0.5. Both must agree.
2. PSRAM 8 MB: how many times does it fit into flash?
3. The model is 14.9 MB. Percentage of flash: 14.9 divided by 16, times 100.
4. The model in fp16 would be 59.6 MB. Does it fit in flash? Write the comparison.
5. Working rows per step: 6 times 512 bytes = 3 KB. Percentage of SRAM.
6. Write 2 sentences: why quantization is mandatory for this board, and why the head lives in PSRAM.
